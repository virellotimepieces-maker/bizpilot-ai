## Cloud Agent

- `npm run dev` serves the app on port 43127.
- `/demo` is browser-only. It does not use PostgreSQL or third-party API keys.
- Local PostgreSQL is for signup and workspace code. The environment start script launches the cluster with `pg_ctlcluster` because `policy-rc.d` blocks `service postgresql start`. `.env.local` (gitignored) holds `DATABASE_URL=postgresql://ubuntu@localhost/bizpilot?host=/var/run/postgresql`, `AUTH_SECRET`, and `APP_URL=http://127.0.0.1:43127`.
- Apply local schema changes with `npx prisma migrate deploy`. Do not export `DATABASE_URL` into the shell before `npm run build`: `scripts/migrate-production.cjs` refuses every database host except Neon, and it skips migration when `DATABASE_URL` is unset.
- `LayoutProps` and the other route types are generated by `npx next typegen` (also by `next dev` and `next build`). Run that before `npm run typecheck` on a clean tree.
- Stripe, OpenAI, Gmail, and Shopify variables are optional for the local demo and for creating an account. Checkout and live AI replies stay off until those values are in `.env.local`.
