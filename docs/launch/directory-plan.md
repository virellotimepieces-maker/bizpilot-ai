# Bizlyro directory submission plan

Manual checklist only. Do not create accounts from this document, and do not submit Bizlyro anywhere until the product page is approved and live. None of these listings is a guaranteed backlink or a guaranteed ranking.

Use the copy in `docs/launch/launch-assets.md`. The URL to submit is https://bizlyro.com/product unless a form has a separate company-website field. In that case, put https://bizlyro.com in the website field and https://bizlyro.com/product in the launch or description link.

Shared assets for every form:

- Product name: Bizlyro AI
- Price: $29.99 per month
- Short description from the launch assets
- Product page URL
- Logo or the existing BL mark
- The screenshot set in the launch assets, in that order
- No reviews, ratings, customer counts, or awards

A public listing often includes a link to the URL you submit. The link may be nofollow, it may be removed later, and this plan does not treat it as a ranking benefit.

## 1. Product Hunt

Priority: first.

Information needed: name, tagline, description, topics, thumbnail, gallery images, first maker comment, pricing, and the product link. A hunter is optional. You can launch it yourself.

URL to submit: https://bizlyro.com/product

Suggested description: the Product Hunt description in the launch assets.

Backlink: the public Product Hunt page usually links to the submitted URL. Whether that link is followed is not guaranteed.

## 2. There's An AI For That

Priority: high, after Product Hunt. It is an AI tool directory.

Information needed: tool name, short description, website, categories or tags, and often a logo. Some forms ask for pricing and a longer description.

URL to submit: https://bizlyro.com/product

Suggested description: the directory submission description in the launch assets. Tag it as a website chatbot and customer-support tool, not as a medical product.

Backlink: a public tool page often links to the website you enter. Follow status is not guaranteed.

## 3. Futurepedia

Priority: high. It is an AI tool directory.

Information needed: name, description, category, pricing, website, and logo. Approval is manual.

URL to submit: https://bizlyro.com/product

Suggested description: the short description in the launch assets.

Backlink: an approved listing often includes a website link. Follow status is not guaranteed.

## 4. FutureTools

Priority: medium. It is an AI tool list.

Information needed: tool name, one-line description, URL, and sometimes a category and pricing note.

URL to submit: https://bizlyro.com/product

Suggested description: the one-sentence description in the launch assets.

Backlink: a listed tool often links out. Follow status is not guaranteed.

## 5. SaaSHub

Priority: medium. It is a SaaS directory.

Information needed: product name, description, website, categories, and alternatives if you know honest ones. Do not invent comparison claims.

URL to submit: https://bizlyro.com/product

Suggested description: the directory submission description in the launch assets.

Backlink: a product profile often links to the website. Follow status is not guaranteed.

## 6. AlternativeTo

Priority: medium. It is a software alternative directory.

Information needed: name, description, platforms (web), license or pricing model (paid subscription), and the official site. Add alternatives only when they are accurate.

URL to submit: https://bizlyro.com/product

Suggested description: the short description in the launch assets. State that it is a paid web app at $29.99 per month.

Backlink: a product page often links to the official site. Follow status is not guaranteed.

## 7. BetaList

Priority: medium. It is a startup directory for products that are new.

Information needed: startup name, pitch, website, maker details, and sometimes a video or screenshots. Use the product story. Do not invent a founding city or a team size.

URL to submit: https://bizlyro.com/product

Suggested description: the one-sentence description plus the $29.99 price.

Backlink: an approved startup page often links to the website. Approval is not guaranteed, and follow status is not guaranteed.

## 8. Crunchbase

Priority: later. It is a company record, not a launch-day gallery.

Information needed: legal or operating name, website, short description, and company details you can verify. Do not invent a founding date, headcount, or funding round.

URL to submit: https://bizlyro.com

Suggested description: the one-sentence description in the launch assets.

Backlink: a company profile can include a website link. That is a company record, not a promise of search ranking.

## 9. G2 and Capterra

Priority: after real customers exist. Do not create either profile as a launch tactic.

Information needed: vendor profile, product description, pricing, and reviews written by real users. Do not write reviews yourself and do not offer a reward that the directory forbids.

URL to submit: https://bizlyro.com/product as the product website, only when you are ready for a public vendor profile.

Suggested description: the long product description in the launch assets.

Backlink: a vendor profile may link to the website. Reviews are not backlinks you control, and a listing is not a ranking guarantee. Skip these until a customer chooses to review the product.

## Do not use

- Bulk directory submitters
- Paid packages that promise a number of backlinks
- Any form that asks you to paste fake testimonials or a user count
- Medical or dental directories that would imply Bizlyro gives clinical advice
